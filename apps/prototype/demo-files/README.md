# Arquivos sintéticos do protótipo

Estes arquivos são exemplos fictícios para testar o fluxo visual do protótipo PWA. Eles não representam documentos reais, não devem ser usados para decisões e não são enviados nem persistidos pelo protótipo.

Para testar, abra a prévia, crie ou selecione um condomínio e use o botão de anexo para escolher um dos arquivos `.txt` desta pasta. Cada arquivo anexado aparece apenas na lista do condomínio ativo durante a sessão atual do navegador.
