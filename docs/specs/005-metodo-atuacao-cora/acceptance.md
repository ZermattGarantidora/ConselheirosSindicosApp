# Critérios de aceitação — Spec 005

| ID | Cenário | Resultado esperado |
|---|---|---|
| AC-501 | Usuário envia “Olá” | Cora responde brevemente, sem busca ou citação documental. |
| AC-502 | Usuário pergunta uma regra do condomínio | Cora usa somente evidência autorizada e mostra fonte verificável. |
| AC-503 | Usuário relata risco físico imediato | Cora prioriza segurança e serviço responsável, sem executar ação externa. |
| AC-504 | Usuário pergunta sobre multa ou disputa | Cora mostra a informação disponível e indica validação humana sem parecer definitivo. |
| AC-505 | Usuário relata conflito entre partes | Cora organiza fatos e próximos passos de mediação, sem decidir culpa ou executar ação externa. |
| AC-506 | Cora orienta um caso conversacional | A resposta tem até 130 palavras, no máximo quatro passos, tom profissional sem frases emocionais e pode destacar ação ou ressalva com `**negrito**`, exibido como negrito sem interpretar HTML. |
