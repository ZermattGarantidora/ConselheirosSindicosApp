# Fixtures

Somente dados sintéticos ou devidamente anonimizados e aprovados podem ser versionados aqui.

`synthetic-corpus.yaml` não representa orientação jurídica nem regras de condomínios reais. Seus textos foram criados exclusivamente para testar isolamento, versão, vigência, citação, conflito e segurança.

Quando PDFs de teste forem adicionados, eles devem reproduzir exatamente o conteúdo declarado no manifesto e conter uma marca visual clara de documento fictício.
