# Fixtures

Somente dados sintéticos gerados artificialmente podem ser versionados aqui.
Documentos reais, inclusive anonimizados, não entram em fixtures, testes, evals
ou benchmarks.

`synthetic-corpus.yaml` não representa orientação jurídica nem regras de condomínios reais. Seus textos fictícios foram criados artificialmente exclusivamente para testar isolamento, versão, vigência, citação, conflito e segurança.

Quando PDFs de teste forem adicionados, eles devem reproduzir exatamente o conteúdo declarado no manifesto e conter uma marca visual clara de documento fictício.
